# 功能规格：WinSpot 窗口探测工具

>

**功能分支**：`001-window-spot-tool`

**创建日期**：2026-09-27

**状态**：草稿

**输入**：用户描述——Windows 窗口工具：拖拽绑定选中窗口并显示 HWND/标题/客户区大小；点击客户区显示相对坐标与颜色（可复制）；框选客户区区域并给出可复制相对坐标；F11 客户区截图且可配置保存路径/格式/质量；以 C# WPF 单文件 exe 交付。

## 用户场景与测试 *(必填)*

### 用户故事 1 - 绑定窗口并查看信息（优先级：P1）

用户打开 WinSpot，将绑定准星拖到可见桌面窗口后松开，工具立即显示该窗口的句柄、标题、客户区大小及相关身份字段。字段可复制，便于记入其它工具或笔记。

**优先级理由**：绑定与身份信息是后续测量与截图的基础。

**独立测试**：绑定记事本（或资源管理器），核对 HWND/标题/客户区大小，并成功复制各字段。

**验收场景**：

1. **给定** WinSpot 已启动且未绑定窗口，**当**用户将绑定控件拖到可见窗口并松开，**则**该窗口成为绑定目标，工具显示其句柄、标题与客户区大小。
2. **给定**已绑定窗口，**当**用户复制句柄或标题，**则**剪贴板为稳定格式文本（句柄仅为十进制数字，例如 `265098`）。
3. **给定**已绑定窗口，**当**用户清除或重新绑定，**则**绑定被清除或替换，且工具不崩溃。

---

### 用户故事 2 - 客户区点击拾取（坐标 + 颜色）（优先级：P2）

绑定窗口后，用户进入拾取模式并点击该窗口客户区内一点。WinSpot 显示相对客户区左上角的坐标及该点颜色，二者均可复制。

**优先级理由**：绑定之后，坐标/取色是日常核心工作流。

**独立测试**：绑定已知窗口，拾取角点与中点，与可信参考比对相对坐标与颜色（在约定容差内）。

**验收场景**：

1. **给定**已绑定窗口且开启拾取模式，**当**用户点击绑定客户区内，**则** WinSpot 显示相对客户区原点的 `(x, y)` 及该像素颜色。
2. **给定**已显示拾取结果，**当**用户复制坐标或颜色，**则**剪贴板格式与界面一致（例如 `x,y` 与 `#RRGGBB`）。
3. **给定**拾取模式开启，**当**用户点击绑定客户区外，**则** WinSpot 忽略该次点击或给出非破坏性提示，且不以错误数据覆盖上次有效拾取。

---

### 用户故事 3 - 客户区框选（优先级：P3）

绑定窗口后，用户进入框选模式并在客户区内拖拽矩形。拖拽过程中显示可见选区（橡皮筋）。WinSpot 以可复制的 `x1,y1,x2,y2`（左上角与右下角，相对客户区）报告区域。

**优先级理由**：区域测量建立在绑定之上；对裁剪/自动化规划有用，但次于单点拾取。

**独立测试**：在绑定客户区内拖出已知大小区域；确认拖拽中橡皮筋可见；核对报告的 `x1,y1,x2,y2`。

**验收场景**：

1. **给定**框选模式且已绑定窗口，**当**用户在客户区内拖拽，**则**拖拽中可见选区轮廓，松开后显示 `x1,y1,x2,y2`（左上/右下，相对客户区）。
2. **给定**框选结果已显示，**当**用户复制区域描述，**则**剪贴板内容恰好为该 `x1,y1,x2,y2` 文本。
3. **给定**拖拽超出客户区边界，**当**用户松开，**则**报告区域被裁剪到客户区内。

---

### 用户故事 4 - 热键客户区截图与导出设置（优先级：P4）

绑定窗口后，用户按 F11（或已配置的截图热键）仅截取客户区，并按已配置的目录、文件名模板、格式与质量保存。设置跨会话持久化。

**优先级理由**：截图价值高但依赖可靠绑定；设置决定日常可用性。

**独立测试**：绑定窗口，设置保存目录/格式/质量，按 F11，打开文件确认仅为客户区内容且尺寸/格式符合预期。

**验收场景**：

1. **给定**绑定窗口可见且保存设置有效，**当**用户按 F11，**则**客户区图像保存到配置位置与格式，且内容与屏幕上合成可见画面一致（非空白/全灰）。
2. **给定**所选格式为 JPEG（默认），**当**用户更改质量后截图，**则**保存文件反映新质量。
3. **给定**绑定窗口已最小化、关闭或无法截取，**当**用户按 F11，**则** WinSpot 给出明确失败提示，且不以损坏/空文件当作成功。
4. **给定**用户更改保存目录/格式/质量，**当**应用重启，**则**仍使用这些设置。

---

### 用户故事 5 - 单文件桌面交付（优先级：P5）

用户下载或构建单个可执行文件，在未单独安装运行时的干净 Windows 10/11 x64 机器上运行 WinSpot。

**优先级理由**：分发交付要求；不阻塞本地构建演示，但发布必须满足。

**独立测试**：发布自包含单文件构建；在未预装 .NET 的环境启动并确认应用可运行。

**验收场景**：

1. **给定**已发布自包含单文件构建，**当**用户在 Windows 10/11 x64 上双击 exe，**则** WinSpot 启动且无需单独安装运行时。

---

### 边界情况

- 目标窗口关闭或绑定后句柄失效。
- 绑定后窗口移动、缩放或标题变化。
- 目标完整性级别高于 WinSpot（可能无法访问/截取）。
- 高 DPI 与多显示器影响屏幕↔客户区换算。
- 全局热键 F11 已被其它程序占用。
- 最小化、被遮罩或完全遮挡的窗口。
- UWP / 独占全屏 / 硬件保护内容可能无法得到准确像素（尽力而为并明确失败）。

## 需求 *(必填)*

### 功能需求

- **FR-001**：系统 MUST 允许用户通过拖放（或等价的从工具拖出）绑定可见桌面窗口。
- **FR-002**：系统 MUST 至少显示绑定窗口的句柄、标题、客户区宽高；字段 MUST 可复制。句柄 MUST 仅以十进制数字显示与复制（无 `0x` 十六进制前缀）。
- **FR-003**：系统 MUST 支持清除与重新绑定目标窗口。
- **FR-004**：系统 MUST 提供拾取模式：在绑定客户区内点击时，报告相对客户区左上角的坐标。
- **FR-005**：系统 MUST 以可复制的 RGB 和/或 HEX 形式报告拾取像素颜色。
- **FR-006**：系统 MUST 提供框选模式：在绑定客户区内选择矩形，拖拽时显示可见橡皮筋，并以可复制的 `x1,y1,x2,y2`（左上角与右下角，相对客户区）报告区域。
- **FR-007**：系统 MUST 将框选结果裁剪到客户区范围内。
- **FR-008**：系统 MUST 注册默认 F11 的截图热键，仅截取绑定窗口客户区。
- **FR-009**：系统 MUST 允许配置截图保存目录、图像格式（至少 PNG 与 JPEG）、JPEG 质量与文件名模板；设置 MUST 本地持久化。默认 MUST 为：JPEG 格式；文件名模板仅时间（例如 `{yyyyMMdd_HHmmss}`），不含窗口标题。
- **FR-010**：当绑定、拾取、框选或截图无法准确完成时，系统 MUST 给出明确错误提示。
- **FR-011**：系统 MUST 以所支持架构的自包含单文件 Windows 可执行文件交付。
- **FR-012**：客户区截图 MUST 使用 DXGI Desktop Duplication（与 Python dxcam 相同思路）捕获合成桌面像素；MUST NOT 以 GDI `BitBlt`/`GetDC` 作为截图后端。

### 关键实体

- **BoundWindow**：当前选中目标；身份（句柄、标题、类名/进程等可得信息）与客户区几何。
- **ClientPointSample**：来自绑定客户区的相对 `(x,y)` 与颜色采样。
- **ClientRegion**：绑定客户区内的相对矩形（原点 + 尺寸）。
- **CaptureSettings**：保存目录、格式、质量、文件名模板、热键。
- **CaptureResult**：客户区截图尝试的成功路径或失败原因。

## 成功标准 *(必填)*

### 可度量结果

- **SC-001**：新用户可在首次启动 30 秒内完成绑定并读到句柄/标题/客户区大小。
- **SC-002**：对标准 Win32 窗口（如记事本），相对拾取坐标与可信参考零像素误差；在正常桌面合成下采样颜色每通道容差 ±1。
- **SC-003**：对屏上已知矩形，框选报告在裁剪后与期望相对边界一致。
- **SC-004**：对可见且可截取窗口，F11 产出图像像素尺寸等于绑定客户区尺寸，在典型开发机上于 2 秒内完成。
- **SC-005**：更改保存设置并重启后，下次截图无需重新配置即使用已存设置。
- **SC-006**：发布的单文件构建可在干净 Windows 10/11 x64 环境启动，无需单独运行时安装程序。

## 假设

- 主要用户为 Windows 10/11 x64 上的开发/测试/自动化作者。
- 首版同时仅绑定一个窗口（无多绑定）。
- 拾取与框选为工具 UI 中互斥模式。
- 默认截图热键为 F11；若 MVP 不要求改键，可延后重映射，但须处理冲突提示。
- 默认图像格式为 JPEG；默认文件名模板为 `{yyyyMMdd_HHmmss}`（无 `{title}`）。
- 截图后端为 DXGI Desktop Duplication（dxcam 等价）；客户区通过对客户区屏幕矩形对应的合成桌面区域裁剪得到。
- OCR、进程注入、脚本化点击，以及独占全屏/受保护内容的完备捕获保证，不在本功能范围内。
- 对受保护/全屏内容允许尽力而为，但失败须对用户可见。
- 除句柄/标题/客户区大小外，「相关信息」在可无提权获得时，可包括类名、进程名/PID、客户区屏幕位置。
- 框选 `x2,y2` 为裁剪后的右下角，使用 `x1+width` / `y1+height`（与归一化拖拽终点一致）。
