# 功能规格：探测测距与复制后空闲

> 语言切换：[English](spec.md) · [中文（仅供阅读）](spec.zh-CN.md)
>
> **说明**：本文件为 `spec.md` 的中文对照阅读版。Spec Kit 流程**仅**使用英文 `spec.md`；更新需求时须同步维护本文件，但不得以本文件作为 `/speckit-*` 的输入。

**功能分支**：`006-probe-range-copy`

**创建日期**：2026-10-04

**状态**：草稿

**输入**：用户描述——1）拾取 Tab 点击复制后自动将探测模式切到「无」，框选 Tab 同理；2）新增探测模式「测距」：选中该 Tab 后，鼠标在绑定窗口内时，测距 Tab 显示当前鼠标位置到客户区中心的距离，以及中心到当前点的射线与垂直方向的夹角（−180~180）；点击后将距离与夹角写入界面，可复制。

**与 `001-window-spot-tool` 的关系**：本增量扩展现有探测 Tab 产品。绑定、截图、复制提示、WinSpot 内外指针规则、Esc /「无」退出、各 Tab 自有结果，除非本规格明确修改，否则仍适用。本规格**仅修订** 001 的 FR-017(d) / SC-010 中关于「复制」的部分：在拾取、框选或测距的**结果复制**成功后 MUST 切到「无」。完成一次拾取/框选/测距采样（点击或拖拽）但未复制时，仍保持当前 Tab（001 对「采样完成」不变）。

## 澄清记录

### Session 2026-10-04

- Q: 拾取/框选点击复制后，探测是否应回到空闲？ → A: 是——这些 Tab 上的结果复制成功后 MUST 选中「无」。Esc 与选择「无」仍为有效退出方式。
- Q: 拾取 Tab 哪次复制会空闲探测？ → A: **复制坐标**或**复制颜色**任一成功即选中「无」。
- Q: 测距结果复制成功后是否也切到「无」？ → A: 是——与拾取/框选相同。仅点击提交、未复制时仍留在「测距」。
- Q: 夹角 0° 与正负号？ → A: **0° = 正上**（客户区 Y 减小）。**正角度 = 顺时针**。因此 +90° 为正右，−90° 为正左，±180° 为正下。

## 用户场景与测试 *(必填)*

### 用户故事 1 - 拾取/框选复制后回到空闲（优先级：P1）

用户绑定窗口，选择「拾取」（或「框选」），完成采样后在该 Tab 的结果区点击复制。复制成功（按钮成功态与顶部「已复制」提示与现网一致）后，WinSpot 自动选中「无」，指针不再对绑定窗口采样。上次拾取/框选结果仍保留在对应 Tab，重新打开即可查看而无需重采。

**优先级理由**：复制后仍停留在探测模式容易误采；复制后空闲是日常流程改动。

**独立测试**：绑定窗口，拾取一点并复制坐标；确认已选中「无」。再用复制颜色验证。框选复制重复验证。再选对应 Tab 仍可见上次结果。

**验收场景**：

1. **给定**已选中「拾取」且显示有效拾取结果，**当**用户成功复制**坐标或颜色任一**，**则**剪贴板格式与界面一致，复制反馈仍出现，并选中「无」Tab，拾取采样停止。
2. **给定**已选中「框选」且显示有效区域，**当**用户成功复制区域，**则**出现复制反馈并选中「无」，框选输入停止。
3. **给定**已选中「拾取」「框选」或「测距」，**当**用户复制的是**绑定区**字段（句柄、标题等）而非探测 Tab 结果控件，**则**不得仅因该次复制而切到「无」。
4. **给定**已成功拾取或框选但尚未复制，**当**用户不点复制，**则**仍保持「拾取」/「框选」选中（001 行为）。
5. **给定**复制后已回到「无」，**当**用户再次选择「拾取」或「框选」，**则**该 Tab 仍显示上次结果（空闲切换不得清空）。

---

### 用户故事 2 - 测距模式实时距离与夹角（优先级：P2）

绑定窗口后，用户选择「测距」Tab。指针在 WinSpot 上仍为正常光标且可完整点击。WinSpot 外使用模式十字光标。指针在绑定客户区上时，测距 Tab **实时更新**：客户区中心到当前客户区相对坐标的欧氏距离，以及由中心指向当前点的射线相对**正上**、**顺时针为正**的有符号夹角（−180~180，含端点折返）。指针离开客户区或回到 WinSpot 时停止实时更新，且不得抹掉已提交的测量。在 WinSpot 外点击绑定客户区，将当前距离与夹角**写入**测距 Tab 的持久结果字段（可复制）。完成点击 MUST NOT 自动切到「无」。

**优先级理由**：新测量能力；交互模型与拾取一致。

**独立测试**：绑定已知尺寸窗口，选「测距」，悬停几何中心（距离约 0），中心正上方（夹角约 0°）、正右（约 +90°），点击冻结后复制，确认已选中「无」。

**验收场景**：

1. **给定**已绑定且已选「测距」，**当**指针在 WinSpot 上，**则**为正常 UI（不测距）。WinSpot 外为十字类模式光标。
2. **给定**已选「测距」且指针在 WinSpot 外的绑定客户区上，**当**指针移动，**则**测距 Tab 以客户区像素显示实时距离与实时夹角，无需点击。
3. **给定**正在显示实时值，**当**用户在 WinSpot 外于绑定客户区内单击，**则**这些值写入测距 Tab 的已提交结果字段，仍保持「测距」选中；之后实时预览可继续跟随指针，但不得立刻覆盖已提交字段，直至下一次点击。
4. **给定**已显示提交的测距结果，**当**用户成功复制测距**结果**（距离、夹角，或包含二者的合并复制），**则**剪贴板与已提交显示格式一致，复制成功反馈与其它复制相同，并选中「无」Tab，测距探测停止。再次选择「测距」仍显示已提交值。
5. **给定**已选「测距」，**当**用户在绑定客户区外（且在 WinSpot 外）点击，**则**忽略或给出非破坏性提示，且不得用无效数据覆盖上次有效提交。
6. **给定**已选「测距」，**当**用户按 Esc **或**选择「无」，**则**测距探测结束并选中「无」；已提交测距结果仍保留在测距 Tab。

### 边界情况

- 未绑定或句柄失效：测距 MUST NOT 编造距离；应给出空闲/错误提示而非虚假数字。
- 指针在客户区但窗口已移动/缩放：中心与坐标 MUST 跟随当前客户区几何。
- 指针恰好在中心：距离为 0；夹角 SHOULD 为稳定定义值（例如 0）而非 NaN。
- ±180 折返：显示 MUST 落在 [−180, 180]，不得超出。
- 高 DPI / 多显示器：与拾取相同的客户区换算精度。
- 客户区宽高奇偶：中心为客户区矩形几何中心（可为半像素）。
- 已提交测距字段为空时复制：MUST NOT 视为成功，也不得切模式。

## 需求 *(必填)*

### 功能需求

- **FR-001**：系统 MUST 将拾取 Tab 任一结果复制控件（**复制坐标**或**复制颜色**）的成功复制视为结束探测并选中「无」。
- **FR-002**：系统 MUST 将框选 Tab 区域复制的成功复制视为结束探测并选中「无」。
- **FR-003**：非拾取、框选或测距**结果**的复制（绑定字段、设置等）MUST NOT 单独导致探测切到「无」。
- **FR-004**：因拾取、框选或测距结果复制而切到「无」时，MUST NOT 清空这些 Tab 上一次存储的结果。
- **FR-005**：完成一次拾取点击或框选拖拽但未复制时，MUST 仍保持「拾取」/「框选」选中（001 FR-017(d) 对「采样完成」仍然有效）。
- **FR-006**：系统 MUST 增加互斥探测 Tab **测距**（英文规格名 Range），与「无 / 拾取 / 框选」并列。选中即激活测距；该 Tab 仅显示测距说明、实时预览与已提交结果。
- **FR-007**：选中「测距」时，指针在 WinSpot 上仍为正常光标与 UI；实时跟踪与点击提交 MUST 仅发生在 WinSpot 外；WinSpot 外光标 MUST 为十字/准星。
- **FR-008**：测距激活且指针在绑定客户区上时，测距 Tab MUST 实时显示：（a）客户区几何中心到当前客户区相对指针位置的欧氏距离（客户区像素）；（b）由该中心经当前点的射线的有符号夹角（度，[−180, 180]），以**正上**（客户区 Y 减小 = 0°）为基准、**顺时针为正**（正右约 +90°，正左约 −90°，正下约 ±180°）。
- **FR-009**：测距激活时，在 WinSpot 外于绑定客户区内左键单击，MUST 将当前实时距离与夹角写入测距 Tab 的已提交、可复制结果字段，且不得切到「无」。
- **FR-010**：已提交测距结果 MUST 可一键复制，文本格式稳定且与界面一致（距离与夹角一并复制，或分控件复制且标签对应字段）。复制体验 MUST 遵循 001 FR-014。任一测距**结果**控件复制成功 MUST 结束探测并选中「无」（与拾取/框选相同）。
- **FR-011**：Esc 与选择「无」MUST 与拾取/框选一样结束测距探测。
- **FR-012**：距离 MUST 使用与拾取坐标相同的客户区像素空间。中心或距离非整数时至少显示一位小数；整数距离可省略尾零。夹角以度为单位，精度须能看出约 1° 变化（至少一位小数）。
- **FR-013**：无法得到有效测距（未绑定、指针不在客户区、换算失败）时，界面 MUST 显示明确的非数字或保留上次提交状态，而不是静默给出错误值。

### 关键实体

- **ProbeMode**：互斥的 无 / 拾取 / 框选 / 测距。
- **ClientRangeSample**：实时或已提交测量：客户区相对指针 `(x,y)`、客户区中心 `(cx,cy)`、欧氏 `distance`、有符号 `angleDegrees`（[−180, 180]）。
- **ClientPointSample** / **ClientRegion**：与 001 相同；复制后空闲不得删除它们。

## 成功标准 *(必填)*

### 可度量结果

- **SC-001**：复制拾取、框选或测距**结果**后，用户无需额外按 Esc 或点 Tab 即处于空闲（「无」）；在再次选择探测 Tab 前不会误采。
- **SC-002**：选中「测距」后，在绑定客户区上悬停时，测距 Tab 上的距离与夹角可连续阅读（用户感知为移动中更新，而非仅点击后更新）。
- **SC-003**：对已知偶数尺寸的标准 Win32 窗口，悬停/点击几何中心时距离为 0（容差 0.5 像素）；中心正上方夹角为 0°（容差 0.5°）；正右约 +90°（容差 0.5°）。
- **SC-004**：用户可用一或两次点击复制已提交的测距距离+夹角，粘贴为稳定文本，并获得与其它字段相同的可感知复制确认。
- **SC-005**：已会用拾取的用户，在选中「测距」后 60 秒内可完成一次提交（悬停 + 点击 + 可选复制）。

## 假设

- 主要用户仍为 Windows 10/11 x64 上的开发/测试/自动化作者（同 001）。
- 「测距」为第四个互斥探测 Tab；本版不要求在目标窗口上绘制覆盖层（数字只出现在 WinSpot 内）。
- 客户区中心为客户区坐标下的 `(width / 2, height / 2)`（浮点），计算距离前不先取整为拾取式整数像素。
- 距离为欧氏距离，非曼哈顿或「仅垂直分量」。
- 实时预览与已提交字段分离：点击冻结提交值；之后移动只更新实时预览，直到下一次点击。
- 测距**点击提交**不自动切到「无」；测距**结果复制**成功则切到「无」。若距离与夹角分控件复制，任一成功即空闲探测（与拾取坐标/颜色规则相同）。
- 绑定区复制永不因复制本身而空闲探测。
- 本功能实现前不改 README；当前 README 仍描述已交付的 001 行为。
- 不在范围：目标窗口上的射线/橡皮筋叠加、键盘微调、跨重启持久化上次测距、多窗口绑定。
